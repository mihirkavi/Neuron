# GitHub Pages Setup

Your website has been pushed to GitHub and is ready to be published!

## Enable GitHub Pages

1. Go to: https://github.com/mihirkavi/Neuron/settings/pages

2. Under "Source", select:
   - Branch: `main`
   - Folder: `/ (root)`

3. Click **Save**

## Your Website URL

Once enabled, your website will be available at:
**https://mihirkavi.github.io/Neuron/**

It may take a few minutes for the site to become available after enabling Pages.

## Notes

- The website files (`index.html`, `styles.css`, `script.js`) are in the root directory
- GitHub Pages will automatically serve `index.html` as the homepage
- Any updates pushed to the `main` branch will automatically update the website
